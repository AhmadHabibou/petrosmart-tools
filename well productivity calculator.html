/// key formulas - well deliverability
Productivity Index (PI): J = Q / (Pr - Pwf) [bbl/d/psi or m3/d/bar]
Darcy IPR: Q = J × (Pr - Pwf) [linear, valid above Pb]
AOF (linear): Qmax = J × Pr [at Pwf = 0]
Darcy steady-state (radial flow):
J_Darcy = 0.00708 × k × h / (μ_o × Bo × (ln(re/rw) - 0.75 + S)) [bbl/d/psi with k in mD]
Vogel IPR (1968): Q/Qmax = 1 - 0.2×(Pwf/Pr) - 0.8×(Pwf/Pr)²
Qmax (Vogel AOF at Pwf=0) = Q_test / [1 - 0.2×(Pwf_t/Pr) - 0.8×(Pwf_t/Pr)²]
Composite IPR (Pr > Pb):
- Above Pb: linear Q = J × (Pr - Pwf)
- Below Pb: Q = Qb + (Jb×Pb/1.8) × [1 - 0.2×(Pwf/Pb) - 0.8×(Pwf/Pb)²]
where Qb = J × (Pr - Pb), Jb = J
Fetkovich: Q = C × (Pr² - Pwf²)^n, n = 0.5-1.0
Gas Darcy IPR (simplified):
Q_g = kh × (Pr² - Pwf²) / (1422 × T_R × μ_g × Z × (ln(re/rw) - 0.75 + S)) [Mscf/d]
Skin from Hawkins formula: S = (k/kd - 1) × ln(rd/rw)
Damage ratio DR: DR = J_damaged / J_undamaged = (ln(re/rw) - 0.75) / (ln(re/rw) - 0.75 + S)
Flow efficiency FE: FE = (Pr - Pwf - ΔPskin) / (Pr - Pwf) = 1 - ΔPskin/(Pr-Pwf)
VLP / Gradient: Pwf_min = THP + gradient × depth + friction_loss
Operating point: Intersection of Q_IPR(Pwf) = Q_VLP(Pwf)
