/// CO2 corrosion - de Waard-Milliams model + NORSOK M-506
CO2 sweet corrosion: CO2 dissolves in water to form carbonic acid (H2CO3), causing uniform corrosion of carbon steel. Rate governed by CO2 partial pressure, temperature, pH, and flow velocity. NORSOK M-506 (2005) is the industry standard model for design.

/// H2S sour service - NACE MR0175 / ISO 15156
Sour service: H2S causes Sulfide Stress Cracking (SSC), Hydrogen Induced Cracking (HIC), and Stress-Oriented HIC (SOHIC). NACE MR0175/ISO 15156 defines sour service threshold: H2S partial pressure > 0.0003 MPa (0.05 psia) AND pH < calculated value. CO2 corrosion continues simultaneously.

/// key formulas
CO2 partial pressure: PCO2 = P_total x yCO2/100 [bar]
H2S partial pressure: PH2S = P_total x yH2S/100 [bar]
de Waard-Milliams (1993 updated):
log(V_CO2) = 5.8 - 1710/(T+273) + 0.67 x log(PCO2) [mm/yr, T in °C]
NORSOK M-506 pH correction factor:
f_pH = 10^(0.46 x (pH - 3.8)) for pH 3.8-6.5 (reduces rate at higher pH)
Temperature correction:
For T < 60°C: use base rate; T > 60°C: protective FeCO3 scale forms → scale factor < 1
Scale factor K_scale ≈ exp(-2500 x (1/(T+273) - 1/333)) for T > 60°C [approximate]
Velocity correction (turbulent/erosion):
f_v = (v/v_ref)^0.8 [proportional to wall shear stress]
Remaining life: RUL = (t_meas - t_min) / CR_actual [years]
NACE sour threshold: PH2S > 0.0003 MPa AND fluid pH < calculated value
CO2/H2S ratio: If PCO2/PH2S < 20: sour corrosion dominates (FeS protective layer)
If PCO2/PH2S > 500: sweet CO2 corrosion dominates
Inhibitor dose (mass): m_dot_inh = Q_water x C_target / (active_pct x 10000) [L/d]
Erosion velocity limit: V_e = C / sqrt(rho_mix) [m/s], C = 100-150 (API RP 14E)
