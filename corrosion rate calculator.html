/// H2S sour service - NACE MR0175 / ISO 15156
Sour service: H2S causes Sulfide Stress Cracking (SSC), Hydrogen Induced Cracking (HIC), and Stress-Oriented HIC (SOHIC). NACE MR0175/ISO 15156 defines sour service threshold: H2S partial pressure > 0.0003 MPa (0.05 psia) AND pH < calculated value. CO2 corrosion continues simultaneously.

/// key formulas
CO2 partial pressure: PCO2 = P_total x yCO2/100 [bar]
H2S partial pressure: PH2S = P_total x yH2S/100 [bar]
de Waard, Lotz and Milliams (1991): log V = 5.8 - 1710/T + 0.67 log fCO2 [mm/yr, T in K, fCO2 in bar]
fCO2 = a x pCO2, log a = P (0.0031 - 1.4/T); scale factor log Fs = 2400/T - 0.6 log fCO2 - 6.7 (Fs <= 1); glycol factor log Fg = 1.6 (log W - 2)
Remaining life: RUL = (t_meas - t_min) / CR_actual [years]
Sour service threshold (ISO 15156-2 / NACE MR0175): pH2S >= 0.3 kPa (0.05 psia); the SSC severity region then depends on pH2S and in-situ pH (ISO 15156-2, Figure 1)
Inhibitor dose (mass): m_dot_inh = Q_water x C_target / (active_pct x 10000) [L/d]
Erosional velocity (API RP 14E): V_e = C / sqrt(rho_m) in ft/s with rho_m in lb/ft3; in SI V_e (m/s) = 1.22 C / sqrt(rho_m kg/m3)
