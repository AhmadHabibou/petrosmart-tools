/// cementing formulas reference
Slurry density (g/cm3): rho_s = (W_cement + W_water + W_additive) / (V_cement + V_water + V_additive)
Yield (L/sack): Y = (m_water/rho_water + m_add/rho_add + m_cem/rho_cem) x 1000 (in liters)
Annular volume: V_ann (L/m) = pi/4 x (D_oh^2 - D_cas^2) x excess / 1000000 (D in mm)
Casing internal volume: V_cas (L/m) = pi/4 x D_cas_ID^2 / 1000000 x 1000
Hydrostatic pressure: P_hydro = rho x g x TVD / 100000 (bar)
ECD: ECD (g/cm3) = mud_density + APL_bar x 100000 / (9.81 x TVD)
Differential pressure (end of job): dP = (rho_cement - rho_disp) x 9.81 x cement_length / 100000 (bar)
Number of sacks: N_sacks = V_total (L) / Yield (L/sack)
Pump time (min): t = V_total (m3) / (Q_bbl_min x 0.158987)
Plastic viscosity (Fann): PV = R600 - R300 (mPa.s)
Yield point: YP = R300 - PV (lbf/100ft2)
Gel strength (10s): GS = R3 (lbf/100ft2)
n (Power Law): n = 3.32 x log(R600/R300)
k (Power Law): k = 0.511 x R300 / 511^n (lbf.s^n/100ft2)
