📖 Key formulas reference
Hydrostatic pressure: P = P0 + rho x g x h (Pa)
In bar: P (bar) = P0 + rho (kg/m3) x 9.81 x h (m) / 100000
In psi: P (psi) = P0 + 0.4335 x SG x h (ft)
Pressure gradient: G (bar/m) = rho x 9.81 / 100000
Pressure gradient: G (psi/ft) = SG x 0.4335
ECD: ECD (kg/m3) = mud_density + APL x 100000 / (9.81 x TVD)
Kill mud weight: KMW = mud_rho + (SIDPP x 100000) / (9.81 x TVD)
Overbalance: OB = BHP - Pformation
Underbalance: UB = Pformation - BHP (kick conditions)
Fracture pressure: Pfrac = fracture_gradient (bar/m) x TVD
EMW: EMW (kg/m3) = P (bar) x 100000 / (9.81 x TVD)
