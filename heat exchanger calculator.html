/// fouling impact and cleaning interval analysis
Fouling: Deposits on heat transfer surfaces (scale, corrosion products, biological growth, process deposits) increase thermal resistance and reduce heat transfer by 20-60% in service. Fouling resistance Rf is added to overall thermal resistance: 1/U_dirty = 1/U_clean + Rf_hot + Rf_cold + wall resistance.

/// all key formulas
LMTD (counter-flow): ΔT1=Th,in-Tc,out | ΔT2=Th,out-Tc,in | LMTD = (ΔT1-ΔT2)/ln(ΔT1/ΔT2)
LMTD (parallel-flow): ΔT1=Th,in-Tc,in | ΔT2=Th,out-Tc,out
F-factor correction: LMTD_eff = F x LMTD_counter | F from P and R parameters
P = (t2-t1)/(T1-t1) (cold side temperature effectiveness)
R = (T1-T2)/(t2-t1) (ratio of capacity rates)
Heat duty: Q = m_h x Cp_h x (T1-T2) = m_c x Cp_c x (t2-t1) = U x A x LMTD_eff
Required area: A = Q / (U_dirty x LMTD_eff)
Overall U (dirty): 1/U_d = 1/U_c + Rh + Rc + t_wall/k_wall
NTU: NTU = U x A / C_min | C_min = min(m_h x Cp_h, m_c x Cp_c)
Capacity ratio: C* = C_min/C_max
Effectiveness (counter): eps = (1-exp(-NTU(1-C*)))/(1-C*exp(-NTU(1-C*)))
Effectiveness (parallel): eps = (1-exp(-NTU(1+C*)))/(1+C*)
Actual Q: Q = eps x C_min x (Th,in - Tc,in)
Number of tubes: Nt = A / (pi x do x L_eff)
Shell ID (triangular): D_s ≈ do x (0.637 x Nt / CTP)^0.5 x (pt/do)
Pressure drop (tube side): dP = f x (L/di) x (rho x v^2 / 2) x N_passes
Pressure drop (shell side): dP = f x N_baffles x D_s x (rho x v_shell^2 / 2) / D_e
