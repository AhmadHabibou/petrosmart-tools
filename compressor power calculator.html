/// intercooling analysis - power savings

/// key formulas - compressor
Compression ratio (per stage): r = P2/P1
Isentropic discharge T: T2s = T1 x (P2/P1)^((γ-1)/γ) [K]
Actual discharge T (isentropic): T2 = T1 + (T2s - T1) / η_is [K]
Isentropic head: H_is = Z1 x R x T1 / MW x (γ/(γ-1)) x ((P2/P1)^((γ-1)/γ) - 1) [J/kg]
Isentropic power: W_is = m_dot x H_is [W]
Shaft power: W_shaft = W_is / η_is [W]
Installed motor power: W_motor = W_shaft / (η_mech x η_driver) [W]
Polytropic exponent n: n/(n-1) = γ/(γ-1) x η_p (for compressors)
Polytropic head: H_p = Z1 x R x T1 / MW x (n/(n-1)) x ((P2/P1)^((n-1)/n) - 1)
Discharge T (polytropic): T2_p = T1 x (P2/P1)^((n-1)/n) [K]
Isothermal power: W_iso = m_dot x Z x R x T1 / MW x ln(P2/P1)
Optimal stage ratio: r_stage = (Pn/P1)^(1/N) for N stages
Intercooling saving: W_N_stages / W_1_stage (at equal total ratio)
/// key formulas - pump
Hydraulic power: W_hyd = rho x g x Q x H [W] (Q in m3/s)
Shaft power: W_shaft = W_hyd / η_pump
Motor input power: W_motor = W_shaft / η_motor
Motor selected (IEC): P_motor ≥ W_shaft x service_factor
Specific speed Ns: Ns = N(RPM) x sqrt(Q(m3/s)) / H(m)^0.75
Ns < 500: Radial centrifugal | 500-3000: Mixed flow | >3000: Axial
NPSHa: P_atm/(rho x g) - P_vapor/(rho x g) ± Z_s - H_f_suction [m]
NPSHa must exceed NPSHr by ≥ 0.5m minimum (ISO 9906)
Affinity laws: Q ~ N | H ~ N^2 | P ~ N^3 (speed change)
VFD savings: P_new/P_old = (N_new/N_old)^3
Torque: T = W_shaft / omega = W_shaft x 60 / (2 x pi x N_RPM) [N.m]
