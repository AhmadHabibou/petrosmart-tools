/// key formulas - separator sizing
Souders-Brown gas velocity: Vg_max = K x sqrt((rho_L - rho_G) / rho_G)
Gas cross-sectional area: A_gas = Qg_actual (m3/s) / Vg_max
Horizontal L/D sizing (gas): L_eff = A_gas x (L/D) / (pi/4 x D)
Liquid retention volume: V_liq = Q_liq (m3/s) x t_retention (s)
Stokes' Law (droplet settling): V_s = (dp^2 x g x (rho_L - rho_G)) / (18 x mu_G)
Droplet settling (liquid in gas): V_s (m/s) = dp^2(m) x 9.81 x delta_rho / (18 x mu_G (Pa.s))
Nozzle momentum: M = rho x v^2 (Pa) - limit: < 4000 Pa for standard inlet
Weir height (3-phase): h_weir = D x (1 - 2 x fw) / 2 + D/2
Oil pad thickness: h_oil = V_oil / (D x L_eff) per unit width
Demister pad pressure drop: dP = C x rho_G x V^2 (C ~ 0.1-0.5 for wire mesh)
