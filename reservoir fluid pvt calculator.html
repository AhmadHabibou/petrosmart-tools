/// key PVT correlations - formulas
Standing (1947) - Bo [RB/STB]:
Bo = 0.9759 + 0.000120 × [Rs × (γg/γo)^0.5 + 1.25×T_F]^1.2
where γo = 141.5/(API+131.5), T_F = temperature in °F

Standing (1947) - Rs [scf/STB]:
Rs = γg × [(P/18.2 + 1.4) × 10^(0.0125×API - 0.00091×T_F)]^1.2048

Vasquez-Beggs (1980) - Rs:
Rs = C1 × γgs × P^C2 × exp(C3×API/T_R); API ≤ 30: 0.0362, 1.0937, 25.7240; API > 30: 0.0178, 1.1870, 23.931

Al-Marhoun (1988): pb = 5.38088×10⁻³ Rs^0.715082 γg^-1.87784 γo^3.1437 T_R^1.32657
Bo = 0.497069 + 0.862963×10⁻³ T_R + 0.182594×10⁻² F + 0.318099×10⁻⁵ F², F = Rs^0.742390 γg^0.323294 γo^-1.202040

Glasø (1980): log pb = 1.7669 + 1.7447 log pb* - 0.30218 (log pb*)², pb* = (Rs/γg)^0.816 T_F^0.172 / API^0.989
log(Bo - 1) = -6.58511 + 2.91329 log Bob* - 0.27683 (log Bob*)², Bob* = Rs (γg/γo)^0.526 + 0.968 T_F

Undersaturated oil compressibility, Vasquez-Beggs [psi-1]:
co = (-1433 + 5 Rs + 17.2 T_F - 1180 γgs + 12.61 API) / (10^5 × P)

Dead oil viscosity (Beal, 1946):
μod = (0.32 + 1.8×10^7/API^4.53) × (360/(T_F+200))^a, a = 10^(0.43+8.33/API)

Live oil viscosity (Chew-Connally, 1959):
μo = A × μod^b, A = 10^[Rs (2.2×10⁻⁷ Rs - 7.4×10⁻⁴)], b = 0.68/10^(8.62×10⁻⁵ Rs) + 0.25/10^(1.1×10⁻³ Rs) + 0.062/10^(3.74×10⁻³ Rs)

Gas Z-factor (Hall-Yarborough):
t = 1/Tpr, A = 0.06125 t exp(-1.2 (1-t)²) | Solve: -A Ppr + (y+y²+y³-y⁴)/(1-y)³ - (14.76t - 9.76t² + 4.58t³)y² + (90.7t - 242.2t² + 42.4t³)y^(2.18+2.82t) = 0
Z = A Ppr / y

Gas formation volume factor Bg [res bbl/scf]:
Bg = 0.00504 × Z × T_R / P [T in °R = (T_F+460), P in psia]

Gas viscosity (Lee, Gonzalez and Eakin, 1966):
μg = 10^-4 × K × exp(X × (ρg/62.4)^Y) where K = (9.4 + 0.02×MW)×T_R^1.5 / (209+19×MW+T_R)
X = 3.5 + 986/T_R + 0.01×MW | Y = 2.4 - 0.2×X
